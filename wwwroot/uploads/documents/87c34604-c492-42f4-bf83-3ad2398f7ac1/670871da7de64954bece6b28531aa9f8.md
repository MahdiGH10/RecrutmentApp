# Backend Architecture — RecruitApp (ASP.NET Core 8)

## Vue d'ensemble

Application de recrutement multi-rôles (Candidat / Recruteur / Admin) construite sur **ASP.NET Core 8** avec architecture en couches propres (Clean Architecture).

## Base de données — SQL Server

### AppDbContext
```csharp
public class AppDbContext : IdentityDbContext<ApplicationUser>
{
    public DbSet<Offre> Offres { get; set; }
    public DbSet<Candidature> Candidatures { get; set; }
    public DbSet<Entretien> Entretiens { get; set; }
    public DbSet<Document> Documents { get; set; }

    protected override void OnModelCreating(ModelBuilder builder)
    {
        base.OnModelCreating(builder);

        builder.Entity<Offre>()
            .HasOne(o => o.Recruteur)
            .WithMany(u => u.OffresPostees)
            .HasForeignKey(o => o.RecruteurId)
            .OnDelete(DeleteBehavior.Restrict);

        builder.Entity<Candidature>()
            .HasOne(c => c.Candidat)
            .WithMany(u => u.Candidatures)
            .HasForeignKey(c => c.CandidatId)
            .OnDelete(DeleteBehavior.Cascade);

        builder.Entity<Candidature>()
            .HasOne(c => c.Offre)
            .WithMany(o => o.Candidatures)
            .HasForeignKey(c => c.OffreId)
            .OnDelete(DeleteBehavior.Restrict);

        builder.Entity<Entretien>()
            .HasOne(e => e.Candidature)
            .WithOne(c => c.Entretien)
            .HasForeignKey<Entretien>(e => e.CandidatureId);
    }
}
```

## Authentification — ASP.NET Identity + JWT

### Configuration (Program.cs)
```csharp
// Identity
builder.Services.AddIdentity<ApplicationUser, IdentityRole>(options =>
{
    options.Password.RequireDigit = true;
    options.Password.RequiredLength = 8;
    options.User.RequireUniqueEmail = true;
})
.AddEntityFrameworkStores<AppDbContext>()
.AddDefaultTokenProviders();

// JWT
var jwtSettings = builder.Configuration.GetSection("JwtSettings");
builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme)
    .AddJwtBearer(options =>
    {
        options.TokenValidationParameters = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidateAudience = true,
            ValidateLifetime = true,
            ValidateIssuerSigningKey = true,
            ValidIssuer = jwtSettings["Issuer"],
            ValidAudience = jwtSettings["Audience"],
            IssuerSigningKey = new SymmetricSecurityKey(
                Encoding.UTF8.GetBytes(jwtSettings["SecretKey"]!))
        };
    });

// Authorization policies
builder.Services.AddAuthorization(options =>
{
    options.AddPolicy("CandidatOnly", p => p.RequireRole("Candidat"));
    options.AddPolicy("RecruteurOnly", p => p.RequireRole("Recruteur"));
    options.AddPolicy("AdminOnly", p => p.RequireRole("Admin"));
});
```

## Filtrage avancé des offres

```csharp
public async Task<IEnumerable<Offre>> GetOffresAsync(OffreFilterDto filter)
{
    var query = _context.Offres
        .Where(o => o.IsActive)
        .AsQueryable();

    if (filter.SalaireMin.HasValue)
        query = query.Where(o => o.SalaireMax >= filter.SalaireMin);

    if (filter.ExperienceMax.HasValue)
        query = query.Where(o => o.ExperienceRequise <= filter.ExperienceMax);

    if (!string.IsNullOrEmpty(filter.Zone))
        query = query.Where(o => o.Zone.Contains(filter.Zone));

    if (filter.Type.HasValue)
        query = query.Where(o => o.Type == filter.Type);

    return await query
        .OrderByDescending(o => o.PublieeAt)
        .Skip((filter.Page - 1) * filter.PageSize)
        .Take(filter.PageSize)
        .ToListAsync();
}
```

### Seeder des rôles
```csharp
static async Task SeedRoles(WebApplication app)
{
    using var scope = app.Services.CreateScope();
    var roleManager = scope.ServiceProvider.GetRequiredService<RoleManager<IdentityRole>>();
    string[] roles = ["Admin", "Recruteur", "Candidat"];
    foreach (var role in roles)
        if (!await roleManager.RoleExistsAsync(role))
            await roleManager.CreateAsync(new IdentityRole(role));
}
```

## Sécurité & bonnes pratiques

- JWT stocké côté client (HttpOnly cookie recommandé en production)
- Validation des inputs avec **FluentValidation** sur tous les DTOs
- **Rate limiting** sur `/api/auth/login` (anti-brute force)
- Recruteurs validés uniquement par Admin avant accès aux features
- Upload de CV limité à PDF/DOCX, max 5 MB
- CORS configuré pour le frontend uniquement
- HTTPS forcé en production (`UseHttpsRedirection`)
